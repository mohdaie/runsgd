About this lab

MapLibre renders OpenStreetMap tiles. Manual destination search uses OpenStreetMap Nominatim. Driving routes use the public FOSSGIS OSRM service. This is an admin development lab, not the production RunSGD route provider.

There is no live traffic or checkpoint-queue modelling. Public test services can be unavailable. GPS positions are processed in your browser and are not saved by this lab.
